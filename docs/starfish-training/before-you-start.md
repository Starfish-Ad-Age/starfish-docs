# Before You Start

Five minutes of setup so the rest of the session goes smoothly. If your machine is already set up, just skim this and confirm each box.

## 1. The app is installed and you're signed in

Open Starfish. You should land in the chat screen, not the setup wizard. If the setup wizard appears, follow it (sign in, pick a plan, paste the API key we gave you). Full steps: [Quick Start](/getting-started/quick-start).

- [ ] Starfish opens to the chat screen
- [ ] Your name/email shows you're signed in

## 2. You can send a message

In the box at the bottom (the **composer**), type:

```
Hello — what can you help me with today?
```

Press **Enter**. You should see a reply stream in word-by-word.

- [ ] You got a reply

That's the whole app, really: you type, it works. Everything else is just connecting tools and learning good prompts.

## 3. The tools you need are connected

Different tracks need different tools connected. Open **Settings → Integrations** and check that the ones for your track show **Connected**:

| If you're doing this track | Make sure this is **Connected** |
|----------------------------|----------------------------------|
| Website Development | **GitHub** |
| Social Media Production | *(nothing extra — image generation is built in)* |
| Ideation Agent | *(nothing extra — web research is built in)* |
| ClickUp Management | **ClickUp** |

If something isn't connected, click **Connect** next to it and follow the prompts. (ClickUp opens a quick sign-in page; GitHub runs a short setup in a panel.) If you get stuck connecting, raise your hand — we'll do it together.

- [ ] The integration(s) for my track show **Connected**

## 4. Know the controls in the chat box

Along the bottom of the composer there are a few controls. You'll use them in the tracks, so find them now:

- **Model selector** — shows the current AI (usually **Auto**). Click it to switch between **Claude, GPT, Gemini** and more — all in one place, no extra tabs. Leave it on **Auto** to let Starfish pick the best model for each message. *This is the one to remember: if an answer isn't great, switch the model and ask again.*
- **Agents** — pick a saved assistant (we'll build one in the Ideation track).
- **Apps** — switch on which connected tools the assistant is allowed to use this conversation (e.g. turn **ClickUp** on before asking about tasks).
- **Media** — switch on **Image** or **Video** generation. *Off by default* because generating costs money, so you flip it on when you actually want a picture.

- [ ] I can find the **Model selector** and the **Agents**, **Apps**, and **Media** dropdowns
