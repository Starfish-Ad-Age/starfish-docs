# Installation

Starfish is currently available for macOS on Apple Silicon.

## System requirements

| Requirement | Minimum |
| --- | --- |
| OS | macOS |
| Chip | Apple Silicon (M-series) |

## Download

1. Go to the [GitHub Releases](https://github.com/cainandanton/starfish-releases/releases) page.
2. Find the latest release at the top of the list.
3. Under **Assets**, click the `.dmg` file to download it.

Always download the most recent version to get the latest features and fixes.

## Install

1. Open the downloaded `.dmg` file.
2. Drag **Starfish** into your **Applications** folder.
3. Eject the disk image.


## First launch

macOS may block the app because it was downloaded from the internet. If you see a warning:

1. Open **Finder** and navigate to **Applications**.
2. Right-click (or Control-click) on **Starfish**.
3. Select **Open** from the context menu.
4. Click **Open** in the confirmation dialog.

You only need to do this once. Subsequent launches work normally from the Dock or Spotlight.


## What's next

After launching for the first time, the [Setup Wizard](/getting-started/setup-wizard) walks you through signing in, connecting your AI Gateway key, a little personalization, and adding your first app.
