# Installation

Starfish is currently available for macOS on Apple Silicon.

## System requirements

| Requirement | Minimum |
| --- | --- |
| OS | macOS |
| Chip | Apple Silicon (M-series) |

## Download

1. Go to [starfishsolutions.ai/intern](https://www.starfishsolutions.ai/intern).
2. Click **Download for Mac** to download the `.dmg` file.

The download is always the most recent version. After you install Starfish, it updates itself.

## Install

1. Open the downloaded `.dmg` file.
2. Drag **Starfish** into your **Applications** folder.
3. Eject the disk image.

## First launch

Open **Starfish** from **Applications**, Launchpad or Spotlight. The app is signed and notarized by Apple.

## What's next

After launching for the first time, the [Setup Wizard](/getting-started/setup-wizard) walks you through signing in, connecting your AI Gateway key, a little personalization, and adding your first app.
