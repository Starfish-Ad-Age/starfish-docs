# Search Studio

Search Studio runs SEO site audits right in the chat. Starfish checks a public website page by page, lists what's wrong ranked by how much it matters, and adds page-speed scores, so you know what to fix first.

## Run an audit

Ask in the chat, for example:

> Run an SEO audit of example.com and tell me what to fix first.

Starfish reads the site's pages, its sitemap and its robots file, then reports back. The audit covers up to 25 pages of the site.

## What you get

- **Issues ranked by importance.** High-impact problems come first, then medium and low. Examples include pages that fail to load or are hidden from search, missing or duplicate page titles and descriptions, missing headings, thin content, and images without alt text.
- **Examples for each issue.** Each issue shows how many pages have it and which ones, so you can go straight to the fix.
- **Page-speed scores** for the home page and two more pages, including a flag for pages that are slow on mobile. Starfish uses your Google connection for these when you have one.

Want it as a document? Ask for the audit as a PDF and Starfish builds a clean report you can share.

## Tips

- Audit a live, public site. Pages behind a login can't be checked.
- Ask follow-ups in the same chat, such as "Write new meta descriptions for the pages missing one."
- Run the audit again after you make changes to see what's left.
